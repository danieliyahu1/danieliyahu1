# Hi there, I'm Daniel 👋

## 💻 Software Engineer | Open Source | Blockchain | AI

I build tools at the intersection of blockchain and AI. Mostly working with the Kaspa ecosystem — creating tools that make blockchain data accessible to AI assistants and building real on-chain applications. Everything I build is open source.

### 🌐 Open Source Contributions

  Run and monitor AI coding tasks from your phone via Telegram, while everything runs locally on your machine.

- **[opencode-notifier](https://github.com/danieliyahu1/opencode-notifier):**
  Desktop notifications and sounds for OpenCode — know when your AI tasks finish or need attention.

---

### 🔗 Blockchain Projects

- **[kticket](https://github.com/danieliyahu1/kticket):**
  On-chain event ticketing on Kaspa. Tickets are covenant-bound assets — organizers deploy them, attendees buy and hold them. Trustless, transparent, and fully on-chain.

- **[forge](https://github.com/danieliyahu1/forge):**
  Create your own tokens on the Kaspa network in minutes. Three fields, one button, done. Every token is a real on-chain covenant-bound asset. Self-custody, no code required. [Try it live](https://forge-jbu3.onrender.com/)

- **[kaspa-statement](https://github.com/danieliyahu1/kaspa-statement):**
  Generate printable receipts for Kaspa transactions. Simple and useful.

---

### 🤖 AI Projects

- **[keren-ai](https://github.com/danieliyahu1/keren-ai):**
  AI-powered chatbot for the Keren-Or scholarship. Docker-first microservices with React frontend, Spring Boot backend, and Groq/OpenAI integration behind an API Gateway.

- **[kaspa-simple-mcp](https://github.com/danieliyahu1/kaspa-simple-mcp):**
  A read-only MCP server that lets AI assistants like Claude, Cursor, and OpenCode query the Kaspa blockchain directly. Check balances, look up transactions, explore blocks — no node required. Works with any MCP-compatible client.

- **[syncthing-simple-mcp](https://github.com/danieliyahu1/syncthing-simple-mcp):**
  MCP server for Syncthing — manage file synchronization through AI assistants.
